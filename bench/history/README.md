# Historical role evaluations

The 20 records cover M38 (eight client/pass pairs), M55, M83 and M96 (four pairs each). M39 was the intermediate single-role rerun between M38 and M55 and falls outside this four-milestone baseline. Each record points to the tracked report and its evaluated freeze commit. The [telemetry schema](../../docs/schemas/powerops-run.schema.json) describes both historical aggregates and individual attempts.

From the repository root, run `python3 bench/history/convert.py --check` to check the committed records. The check accepts LF or CRLF checkouts, including on Windows, and rejects any other byte differences and any missing or extra JSON files. Run the script without arguments to regenerate the records. Use `--out <dir>` to write a separate copy or `--check --out <dir>` to check one. The converter writes UTF-8 without a BOM, with two-space indents and LF line endings.

| Field | Reading the historical records |
|---|---|
| Identity | One record per milestone, client and pass. The date is the final UTC day of the run window. Client effort and requested model come from Setup. A mixed family-wide model report leaves the pass's reported model null. Each solution pass has the seed lineage. A plan pass spans multiple lineages. |
| Cost | Totals cover valid runs. Claude reports input plus cache writes as one number in `uncached_in_combined`, alongside cached reads and output. M83 and M96 inherit this definition of the Claude `Uncached in` column from M38 and M55. Its USD figure uses list prices (`ratecard`). Codex reports uncached input in `tokens_in`, cached reads and output. Its USD basis is `unknown`. M38 gives the cost in tokens and time of including replacements only for Codex as a whole. |
| Quality | Score is found / total across the pass's keyed flaws. Solution passes retain both shown and not-shown fractions. M38 plan passes retain the plan-flaw fraction. Severity is unavailable for keyed hits. Clean Highs count as false only under the report's final settlement. The M83 and M96 notes give the alternate scorer reading across families. |
| Time | Wall seconds sum the valid runs of that client and pass. The reports give no per-pass tool, approval or human times, turn counts, tool-call totals or question counts. |
| Reliability | All aggregates completed. Retries count replacement runs and exclusions count cases removed from the denominator. Each case had one valid run. Neither per-task pass rates nor repeated-attempt reliability were measured. Stray writes, outside reads and tenant claims used separate protocols and supply no T-SAFETY violation count. |

Unavailable measurements are explicitly `null`. A measured absence, such as zero replacements, is `0`. M55, M83 and M96 report pooled scorer tokens only at the milestone level, so each pass has `judge_tokens: null`. Judge dollars are also unavailable per pass. CI runner seconds and Copilot Studio credits are also unavailable. Optional recall fields apply to their corresponding kind of pass.
