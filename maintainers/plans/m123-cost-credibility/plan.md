## Assumptions

Each Microsoft claim was checked on 2026-11-22 by `powerops-researcher` (Opus, Learn and open Microsoft repositories; `decisions.md` Log has the details):

- A1. `workflow.modernflowtype` (choice `workflow_modernflowtype`, default 0): 0 `PowerAutomateFlow`, 1 `CopilotStudioFlow`, 2 `M365CopilotAgentFlow` (*workflow table reference*). An export writes `<Category>5</Category>` and `<ModernFlowType>1</ModernFlowType>` in the `<Workflow>` element of the `.json.data.xml` file: observed in the Power-CAT Copilot Studio Kit's `AgentReviewerFlow` (microsoft/Power-CAT-Copilot-Studio-Kit, `AgentReviewTool/SolutionPackage/src/Workflows/`). Every existing fixture writes `0`.
- A2. An agent flow's definition uses the cloud flow schema; its trigger is `Request` with kind `Skills` and it answers with a `Response` action of kind `Skills`: observed in that export, not on Learn. The *Agent flows FAQ* (2026-10-22) says the trigger and response are what lets an agent call the flow. The driver keys on `ModernFlowType`, not on the trigger, because a converted flow may keep its own trigger.
- A3. Agent flows: 13 Copilot Credits per 100 actions, each trigger run one action (*Billing rates and management*, 2026-11-17); not under Power Platform request limits (*Requests limits and allocations*); new runs blocked with `InsufficientMcsCredits` when credits run out, runs in progress finish (*Agent flows overview*, 2026-11-12; *usage limit errors*); no Power Automate licence needed and premium connectors allowed (*Agent flows FAQ*); test runs and "When an agent calls the flow" runs by a signed-in user with a Microsoft 365 Copilot licence aren't charged (not when the agent runs on its own). The *Agent flows FAQ* also says "You can't call desktop flows from agent flows at this time", so a `RunUIFlow_V2` action in an agent flow is not a `desktop-flow-call`.
- A4. `ModernFlowType` 2: not found. The workflow table gives only the label `M365CopilotAgentFlow`; no Learn page ties it to a product or a meter. Two candidates (the Workflows agent's flows in Microsoft 365 Copilot, *Microsoft Copilot workflows environment*, 2026-11-03; Copilot Studio workflows, billed in Copilot Credits, *Overview of usage-based billing*) are unproven to be value 2, and no open export with value 2 was found. So such a flow gets a `notRead` line, not a driver, and no Power Automate driver.
- A5. AI Builder actions are `OpenApiConnection` actions on the Dataverse connector with an `operationId` starting `aibuilderpredict_`: `aibuilderpredict_customprompt` ("Run a prompt": Learn's advanced connector policies tutorial, 2026-11-21; microsoft/power-platform-skills; pnp/powerplatform-samples), `aibuilderpredict_gptpromptengineering` and `aibuilderpredict_keyphraseextraction` (pnp samples). The Power-CAT kit's agent flow gives the same action the `apiId` `providers/Microsoft.ProcessSimple/operationGroups/aibuilder`, so the driver matches the `operationId` only. Learn's connector reference lists no AI Builder operation. The search of open repositories was partial, so other ids may exist; every one seen starts with the prefix.
- A6. The generic "Predict" action's cloud-flow `operationId` was not found; it is not matched (Won't build).
- A7. *End of AI Builder credits* (2026-10-02): end of sales of the capacity add-ons 2025-11-01; end of life of the add-ons and of seeded credits 2026-11-01; existing credits last to contract end; apps and flows use AI Builder credits, then Copilot Credits, then are blocked; agents and agent flows use Copilot Credits only; trials discontinued. ECO-0028 said "since 2026-11-01 no new add-ons", which Data row 8 corrects.
- A8. Learn disagrees: *Overview of licensing* (2026-09-09): "A Power Automate flow that uses any AI Builder action is a premium flow."; *Licensing and AI Builder credits* (2026-10-09): the action "doesn't transform it into a premium flow", and "Seeded credits will be removed on November 1, 2026."; *Types of Power Automate licenses* (2026-09-22) still lists 5,000 AI Builder credits a month with Premium, Process and Hosted Process. Both agree an app using AI Builder is premium.
