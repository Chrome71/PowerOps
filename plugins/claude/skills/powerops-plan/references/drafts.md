# Drafts a Microsoft tool generated

Read this only when the person's draft (`SKILL.md` section 2 step 5) came from one of three tools: a Plans document from Power Apps (its PDF export or pasted text), what they gave Cowork's App skill, or a description given to Apps in Copilot Studio (preview). These tools generate choices the person may never have read, so a generated choice settles nothing until the person endorses it. A choice the person wrote or changed themselves is logged as section 2 step 5 says.

1. **The log.** Log each choice the tool generated under `## Log` as `- from the draft (generated): <choice>`, with no person mark, and write it under Assumptions as `generated: <choice>`.
2. **Never settled by a draft.** A generated choice never settles the classes that are never defaults (section 6: the cost tier, `Held`, environments, security roles, the data-round questions), nor the route: ask those as usual.
3. **One question for the rest.** With the first questions, ask once "Keep these N generated choices?": **Keep all** (recommended) or **Change some**, then ask about those. Log `generated kept: <N>` or `generated changed: <labels>` with its mark under `## Log`, not as a `### Q`.
4. **The fast path.** In the fast path (section 8) generated choices stay `generated:` Assumptions and settle nothing, so it still asks nothing beyond the route, the prefix and the sketch question.
5. **Licence and tenant facts.** A licence or tenant fact in a generated draft is `unknown`, never the person's answer and never `yes (read)`.

- https://learn.microsoft.com/power-apps/maker/plan-designer/plan-designer and https://learn.microsoft.com/power-apps/maker/plan-designer/create-plan: Plans is generally available, its content is generated by agents and the person reviews it step by step, and it is exported only as PDF.

Learn shows no mark of which plan content was generated once accepted, so the `generated` mark is PowerOps's own rule.
