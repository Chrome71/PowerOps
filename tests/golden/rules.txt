PO001 error  Flow uses a connection reference that is not defined
  fix: Add the connection reference to the solution, or add the solution that owns it as a dependency.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO001.md
PO002 error  Required environment variable has no default or current value
  fix: Give the variable a default value, or supply the value at deployment time and keep it out of the solution.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO002.md
PO003 error  Missing dependency has no owning solution
  fix: Add the missing component to the solution, or import the solution that provides it first.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO003.md
PO004 error  Flow calls a child flow that is not defined
  fix: Add the child flow to the solution, or add the solution that contains it as a dependency.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO004.md
PO005 warning Connection reference is not used by any flow or app
  fix: Remove the connection reference from the solution, or use it in the flow or app that needs it.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO005.md
PO006 warning Flow contains a hard-coded environment or SharePoint site URL
  fix: Remove the URL where the platform can use the current environment, otherwise read it from an environment variable whose value is set per environment at deployment.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO006.md
PO007 warning Environment variable default value looks environment-specific
  fix: Leave the default empty and set the value per environment at deployment time, or use a default that is valid everywhere.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO007.md
PO008 warning Environment variable ships a current value
  fix: Remove the current value before export, and supply per-environment values with deployment settings.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO008.md
PO009 warning Component name does not use the publisher prefix
  fix: Recreate the component under the solution's publisher, or keep it in a solution of the publisher that owns it and add that solution as a dependency.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO009.md
PO010 warning Solution uses a default or generated publisher prefix
  fix: Create a publisher with a meaningful prefix and build the solution under it.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO010.md
PO011 warning Cloud flow is turned off
  fix: Turn the flow on before export, or remove it from the solution if it is no longer needed.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO011.md
PO012 warning Dataverse row-updated trigger has no filter columns
  fix: Set the trigger's filter columns to the columns whose update should start the flow.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO012.md
PO013 error  Root component has no source folder in the YAML layout
  fix: Commit the component's folder and list it in solutioncomponents.yml, or remove the component from rootcomponents.yml.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO013.md
PO014 warning Canvas app formula contains a hard-coded environment or SharePoint site URL
  fix: Remove the URL where the platform can use the current environment, otherwise read it from an environment variable whose value is set per environment at deployment.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO014.md
PO015 error  Dataverse row-created trigger has filter columns
  fix: Clear the trigger's filter columns, or change its change type to Create or Update.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO015.md
PO016 warning Cloud flow has more than 50 actions or more than 4 levels of nesting
  fix: Move self-contained parts of the flow into child flows, and reduce nested scopes, conditions and loops.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO016.md
PO017 warning Cloud flow runs a loop inside a loop
  fix: Replace the inner loop with one query, filter or bulk action over the whole set, or fetch the related rows with the outer query's expand option and use one loop.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO017.md
PO018 warning Canvas app formula calls Patch or ForAll inside ForAll
  fix: Pass the ForAll result to one Patch call instead of calling Patch inside ForAll, and avoid nesting ForAll.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO018.md
PO019 warning Power Pages Web API fields setting is *
  fix: Replace * with the comma-separated logical names of the columns the site needs, or set UseFieldsFromView to True with a view that holds them.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO019.md
PO020 warning Power Pages Web API is enabled for a table with no fields setting
  fix: Add a fields site setting for the table with the columns the site needs, or set its UseFieldsFromView site setting to True with a view that holds them.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO020.md
PO021 warning Power Pages table permission has no web role
  fix: Associate the table permission with the web roles that need it, or delete it.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO021.md
PO022 warning Power Pages child table permission is not in effect through its parent
  fix: Give the parent table permission the child's web roles or remove them from the child, and keep the parent active.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO022.md
PO023 warning Power Pages table permission lets anonymous users create, write or delete
  fix: Remove create, write and delete from the anonymous role's table permission, or grant them to a role that requires sign-in.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO023.md
PO024 error  Site map opens a custom page that is not in the solution
  fix: Add the custom page to the solution, or add the solution that holds it as a dependency.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO024.md
PO025 warning Model-driven app has more than 25 custom pages, 10 connectors or 20 connection references
  fix: Move custom pages to another app, or remove pages and connections, until the app has at most 25 custom pages, 10 connectors and 20 connection references.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO025.md
PO026 warning Code app depends on a table or connector that is not in the solution
  fix: Add the table or connector to the solution, or add the solution that holds it as a dependency.
  https://github.com/Chrome71/PowerOps/blob/main/docs/rules/PO026.md
