2. Cut 128 words of existing text

(answered by: agent m93 session, on the owner's standing direction)

### Q3. Where does `logic.md` say a starting status is enforced?
1. A synchronous plug-in on Create; column security for columns only a later role fills (recommended)
2. Column security for both
3. In your own words
Answer: A plug-in. Learn says `statecode` and `statuscode` can't be secured, documents status reason transitions only for changes to an existing row, and leaves open whether a business rule can use `statuscode`; the fix plan's list (column security, create permission, transition, business rule, plug-in) is narrowed to what Learn supports. (answered by: agent m93 session, on the owner's standing direction)
