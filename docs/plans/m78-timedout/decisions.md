# Decisions: m78-timedout

## Round 1

### Q1. Learn doesn't say what status a Scope, If, Switch or loop gets when an action inside it times out and nothing inside handles it. What does the simulator do with such a container?
1. It is `Failed`, as the fix plan agreed. But the test is `unsupported` when an action after it lists only one of `Failed` and `TimedOut` for it, and the message says to list both. No test then passes on a choice Learn doesn't settle. It costs about 20 more lines in `RunBlock` and the containers, and the guard tests (recommended)
2. It is `Failed`, and `FLOW-TESTS.md` calls this the simulator's choice. This is the fix plan's rule as written and the smallest change. But a Catch that lists only `Failed` runs offline, and in the cloud it may be skipped, if the container there is `TimedOut`
3. It is `TimedOut`. A Catch that lists only `TimedOut` then runs offline, and in the cloud it may be skipped, if the container there is `Failed`

Answer: 1 (answered by: person, 2026-11-08). Done when 4 and Data rows 4, 6 and 7 follow it.
