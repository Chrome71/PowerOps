## Known incompatibilities and preview limits

- `pac` builds older than 2.13.1 are untested: [FOUNDATION section 8](../FOUNDATION.md#8-research-topics-still-open), the Phase 3b item.
- The `pac solution unpack` layout and Dataverse Git integration's YAML layout differ, and unpacking into a YAML folder added XML beside the YAML and deleted other files: [FOUNDATION section 8](../FOUNDATION.md#8-research-topics-still-open), the Phase 1 item, and `docs/HANDOFF.md`.
- `pac power-automate list-cloud-flows --json` is a preview command with no documented fields (`AGENTS.md`).
- The Claude desktop app's Code tab showed no confirmation form for `deploy_apply`, and Codex's form has no Decline: `docs/HARNESS.md`.
