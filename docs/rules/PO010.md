# PO010: Solution uses a default or generated publisher prefix

Severity: warning

## What it finds

The publisher prefix is `new`, is a generated `cr` plus three or four hex digits (for example `cr5a1`), or the publisher unique name starts with `DefaultPublisher`.

## Why it matters

Generated and default prefixes differ between environments and do not identify your team, so names can clash when solutions are combined.

## How to fix

Create a publisher with a meaningful prefix (for example `contoso`) and build the solution under it.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
