# PO011: Cloud flow is turned off

Severity: warning

## What it finds

A cloud flow in the solution has state "off" (draft).

## Why it matters

The flow ships switched off, so the automation silently does not run after deployment, or the flow is left over and should not ship.

## How to fix

Turn the flow on before export, or remove it from the solution if it is no longer needed.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
