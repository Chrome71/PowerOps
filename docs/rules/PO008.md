# PO008: Environment variable ships a current value

Severity: warning

## What it finds

The solution contains a current value for an environment variable (a value stored in the exported solution, not only the default).

## Why it matters

A shipped current value overrides the target environment's own value and can leak settings from the source environment.

## How to fix

Remove the current value before export, and supply per-environment values with deployment settings.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
