# PO008: Environment variable ships a current value

Severity: warning

## What it finds

The solution contains a current value for an environment variable (a value stored in the exported solution, not only the default).

## Why it matters

A shipped current value is applied on import, so no prompt appears and the source environment's value is used. It can leak settings from the source environment.

## How to fix

Remove the current value before export, and supply per-environment values with deployment settings.

## Sources

Sources: [Environment variables overview](https://learn.microsoft.com/power-apps/maker/data-platform/environmentvariables), [Environment variables in custom connectors](https://learn.microsoft.com/connectors/custom-connectors/environment-variables). verified: 2026-10-19

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
