# PO002: Required environment variable has no default or current value

Severity: error

## What it finds

An environment variable definition marked required has neither a default value nor a current value in the solution.

## Why it matters

The import prompts for a value or fails in unattended deployments, and flows that read the variable break.

## How to fix

Give the variable a default value, or supply the value at deployment time (for example in a deployment settings file) and keep it out of the solution.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
