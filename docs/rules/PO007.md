# PO007: Environment variable default value looks environment-specific

Severity: warning

## What it finds

An environment variable's default value is a URL, a GUID or an email address.

## Why it matters

Default values travel with the solution to every environment, so an environment-specific default silently points other environments at the wrong target.

## How to fix

Leave the default empty and set the value per environment at deployment time, or use a default that is valid everywhere.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
