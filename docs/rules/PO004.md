# PO004: Flow calls a child flow that is not defined

Severity: error

## What it finds

A cloud flow has a "Run a Child Flow" action (a `workflowReferenceName`) whose flow id is not a workflow in this solution and is not declared as provided by a dependency.

## Why it matters

The parent flow cannot call the child flow, because it does not exist in the target environment.

## How to fix

Add the child flow to the solution, or add the solution that contains it as a dependency.

## Sources

Sources: [Create child flows](https://learn.microsoft.com/power-automate/create-child-flows). verified: 2026-10-19

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
