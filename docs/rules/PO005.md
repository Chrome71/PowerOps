# PO005: Connection reference is not used by any flow or app

Severity: warning

## What it finds

A connection reference in the solution is not used by any cloud flow, and its logical name or connector id does not appear in any canvas app of the solution. The canvas app check is a text search, so it prefers to miss a warning rather than raise a false one.

## Why it matters

Unused connection references still ask for a connection on import and add clutter to every deployment.

## How to fix

Remove the connection reference from the solution, or use it in the flow or app that needs it.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
