# PO005: Connection reference is not used by any flow or app

Severity: warning

## What it finds

A connection reference in the solution is not used by any cloud flow, and its logical name or connector id does not appear in any canvas app of the solution. The canvas app check is a text search, so it prefers to miss a warning rather than raise a false one. Microsoft's page on connection references says canvas apps use them only for implicitly shared (non-OAuth) connections, such as SQL Server authentication, so a reference an app uses through an OAuth connection can look unused unless the connector id appears in the app.

## Why it matters

Unused connection references still ask for a connection on import, so every deployment carries one more connection to set up.

## How to fix

Remove the connection reference from the solution, or use it in the flow or app that needs it.

## Sources

Sources: [Create a connection reference](https://learn.microsoft.com/power-apps/maker/data-platform/create-connection-reference). verified: 2026-10-28

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
