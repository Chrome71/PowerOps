# PO003: Missing dependency has no owning solution

Severity: error

## What it finds

The solution manifest lists a missing dependency (a component the solution needs but does not contain) and no other solution is named as its owner. Dependencies on the same component are reported once, with the components that need it.

## Why it matters

The target environment must already contain the component, otherwise the import fails.

## How to fix

Add the missing component to the solution, or import the solution that provides it first. If another solution owns it, make sure the manifest names that solution.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
