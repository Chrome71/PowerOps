# PO012: Dataverse row-updated trigger has no filter columns

Severity: warning

## What it finds

A cloud flow starts with the Dataverse "When a row is added, modified or deleted" trigger, the trigger's change type includes Update (Update, Create or Update, Update or Delete, or all three), and no filter columns are set.

## Why it matters

The flow runs on every update of the table, whichever column changed. This wastes runs, can cause loops when the flow itself updates the row, and hits Power Platform request limits.

## How to fix

Set "Select columns" (filter columns) to the columns whose change should start the flow.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
