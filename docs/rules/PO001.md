# PO001: Flow uses a connection reference that is not defined

Severity: error

## What it finds

A cloud flow refers to a connection reference (by logical name) that is neither in this solution nor declared as provided by a solution it depends on.

## Why it matters

The flow has no connection reference to bind, so it cannot use a connection. The import reports a missing dependency, or the flow cannot be turned on.

## How to fix

Add the connection reference to the solution (for example `contoso_sharedsharepointonline_abc12`), or add the solution that owns it as a dependency.

## Sources

Sources: [Create a connection reference](https://learn.microsoft.com/power-apps/maker/data-platform/create-connection-reference), [Missing dependency on solution import](https://learn.microsoft.com/troubleshoot/power-platform/dataverse/working-with-solutions/missing-dependency-on-solution-import). verified: 2026-10-19

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
