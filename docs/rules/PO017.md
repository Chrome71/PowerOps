# PO017: Cloud flow runs a loop inside a loop

Severity: warning

## What it finds

A For each (`Foreach`) or Do until (`Until`) loop inside another loop, at any depth. A Scope or Condition between the two loops doesn't hide it. There is one finding per inner loop, naming it and its nearest enclosing loop.

## Why it matters

Learn says nested For each loops multiply iterations: two loops of 10 iterations are 100. This can approach limits and quotas and slow the flow.

Learn names For each. This rule also counts Until, which repeats its actions too (60 times by default, up to 5,000, per Learn's limits page).

## How to fix

Replace the inner loop with one query, filter or bulk action over the whole set. Where the inner loop reads rows related to the outer loop's rows, fetch them in the outer query with OData expansion (the Expand Query parameter) and $select, and process them in one loop; this is the case Learn documents, with Dataverse List rows as the example.

Not every nested loop can be flattened, such as an Until that polls for each item. Keep it, and baseline the finding as Suppress says.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
