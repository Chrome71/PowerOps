# PO009: Component name does not use the publisher prefix

Severity: warning

## What it finds

An environment variable, connection reference or table (entity) has a name whose prefix, the text before the first underscore, differs from the solution publisher's prefix. Other component types are not checked.

## Why it matters

Components owned by another publisher usually mean the solution was built from copied or unrelated parts, which makes ownership and upgrades unclear.

## How to fix

Create the component under the solution's publisher, or move it to a solution owned by the publisher that matches its prefix.

## Suppress

To accept the finding for now, run `powerops baseline` and use `powerops analyze --baseline powerops-baseline.json`. A baselined finding is matched on solution, rule, component and message.
