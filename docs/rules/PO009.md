# PO009: Component name does not use the publisher prefix

Severity: warning

## What it finds

An environment variable, connection reference or table (entity) has a name whose prefix, the text before the first underscore, differs from the solution publisher's prefix. Other component types are not checked.

## Why it matters

Components owned by another publisher can mean the solution was built from copied or unrelated parts, which makes ownership and upgrades unclear. This is a heuristic, not a Microsoft rule.

## How to fix

Ownership of a component cannot move to another publisher. Recreate the component under the solution's publisher, or keep it in a solution of the publisher that owns it and add that solution as a dependency.
